# EAP 心理咨询助理客服 Agent

## 项目简介

这是一个基于 AI 的 EAP（员工援助计划）心理咨询助理客服系统，能够将传统客服 Agent 的能力与专业心理咨询服务相结合。

Agent 能够独立完成以下工作：
- 接待用户来访，进行情绪安抚与共情
- 识别用户的心理问题类型与风险等级
- 根据风险等级进行分级处理与分流
- 自动生成结构化的咨询记录

## 设计背景

EAP 心理咨询场景中，大量来访者的问题属于轻度情绪困扰（焦虑、压力、失眠等），可以通过初步评估、自助建议和资源推荐来解决。但专业咨询师资源有限，需要一个能够完成初步接待、评估、分流的 AI 助理，提升服务效率，同时确保高风险案例得到及时的专业干预。

## 核心功能

### 1. 接待与情绪安抚
- 用户进入后，Agent 主动问候，创造安全的倾诉空间
- 通过共情回应，帮助用户平复情绪
- 识别用户当前的情绪状态（焦虑/抑郁/愤怒/无助等）

### 2. 问题分析与需求识别
- 判断问题类型：情绪困扰、人际关系、职场压力、家庭婚姻、睡眠问题、危机风险
- 区分表层诉求与潜在需求（例如"失眠"可能源于焦虑）
- 使用标准化量表辅助评估（PHQ-9、GAD-7、PSS-10）

### 3. 风险等级评估与分级处理
| 风险等级 | 判定标准 | 处理方式 |
|---------|---------|---------|
| 低风险 | 轻度情绪波动，无自伤倾向 | 自助建议（呼吸放松、认知调整）、推荐资源 |
| 中风险 | 持续困扰，影响日常功能 | 建议预约咨询师，提供预约方式 |
| 高风险 | 出现自杀自伤念头或计划 | 立即触发危机干预，提供热线，建议紧急求助 |

### 4. 记录与总结
- 自动生成咨询记录摘要（问题类型、风险等级、处理建议）
- 输出结构化用户需求标签，便于后续统计分析

## 技术实现

- **平台**：字节跳动 扣子（Coze）
- **核心技术**：Prompt Engineering + Knowledge Base + Workflow
- **无需编写代码**，通过可视化工作流编排实现

### 架构设计

```
用户输入 → 情绪识别 → 问题分析 → 风险评估 → 分级处理 → 生成记录
    ↓           ↓           ↓           ↓           ↓           ↓
  共情回应   情绪标签    问题分类    风险等级    分流建议    结构化摘要
```
